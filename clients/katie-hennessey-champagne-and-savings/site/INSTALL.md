# Installing the Champagne & Savings pages in Showit

Each .txt file is one complete page. For each page:
1. Create the Showit page with the URL in the table.
2. Add ONE Embed Code block, paste the whole .txt file in, and stretch the block full width on the desktop canvas AND separately on the mobile canvas.
3. Save, PUBLISH, then hard refresh the live page (Cmd+Shift+R). The Showit editor shows embeds as gray boxes. Only the published site is truth.
