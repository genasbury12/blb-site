Page codes, ready to copy.

  1. Press Copy code on a page below.
  2. In Showit, open that page, add one Embed Code block, and paste the whole thing in.
  3. Stretch the block full width on the desktop canvas, then switch to the mobile canvas and stretch it there too.
  4. The editor shows a gray box. That is normal. Save, Publish, then hard refresh the live page (Cmd+Shift+R).
