Section one

How this works now

Four steps. Once you have done it twice it takes about ten minutes.

  1. Give Claude the page. Upload the file into a Claude chat, or paste the whole thing in.
  2. Tell it what you want. Paste your Standing Instructions from Section 2, then describe the change in your own words.
  3. Get the finished file back. Claude returns the complete page with your change made, and a short list of what it did.
  4. Paste it into Showit and publish. Then check it in an incognito window.

You are the editor, not the typist. Your job is to say clearly what you want and then check the result. Claude does the fiddly part. You never have to find a comma in a wall of code again.

Claude is very good at this and still gets things wrong sometimes. That is why Section 5 exists and why you always keep a copy of the old file. Checking takes two minutes and saves an evening.

What you need

  • A Claude account. The free one works, a paid one handles these large files more comfortably.
  • The eleven page files, kept in one folder on your computer.
  • Your Showit login.
  • A plain text editor for saving files. TextEdit, Notepad, or the free VS Code. Never Word.
Section two

Your Standing Instructions

This is the most important thing in this whole document. Paste it at the top of every request.

Claude does not know your brand rules unless you tell it. Without this block it will cheerfully add em dashes, rewrite things you did not ask it to touch, or hand you a fragment instead of the whole file. With it, you get back exactly what you need.

You are helping me edit one page of my membership website.
Follow these rules for every change.

ABOUT THE SITE
- Purposeful Pennies, a warm faith friendly money membership for
  one income families. My name is Brooke.
- Each page is one standalone HTML file that gets pasted into
  Showit as Custom Head HTML.
- The members area is locked with MemberSpace.

RULES YOU MUST FOLLOW
1. Give me back the COMPLETE file, from the first line to the
   last line. Never a snippet. Never say the rest stays the same.
2. Change only what I ask for. Leave everything else exactly
   as it is, including spacing and comments.
3. No em dashes and no en dashes anywhere, ever. If you need a
   separator use the diamond character.
4. Never remove or alter the block commented
   SHOWIT OVERRIDE ARMOUR. It stops my menu going invisible.
5. Do not change anything inside the style section unless I
   specifically ask you to.
6. Keep every attribute starting data-ms- and every link with
   class ms-link exactly as it is. Those are my membership plugin.
7. All internal links look like /members-something with hyphens.
   Never /members/something with slashes.
8. Keep my voice warm, plain and calm. No hype, no exclamation
   marks, no words like hustle, boss babe, girlboss or manifest.
9. If what I am asking would break something, or contradicts
   something already written elsewhere on the page, tell me
   before you change it.
10. After the file, list in plain English exactly what you
    changed, so I can check it.

WHAT I WANT CHANGED

Save this somewhere you can grab it fast. A note on your desktop, a pinned note on your phone, or the top of a Google Doc. You will use it several times a month.

Rule 1 is the one that matters most. Without it Claude often replies with just the bit it changed, which is useless to you because you need the whole file to paste into Showit. If you ever get back a fragment, just reply: please give me the complete file from the first line to the last.

Section three

The four steps in detail

Step 1 ◆ Give Claude the page

  1. Make a copy of the file first. Duplicate it and put today’s date in the name, like MemberLibrary-2026-08-01.html. This is your undo button.
  2. Start a new Claude chat.
  3. Upload the file using the paperclip or plus button. This is better than pasting, because these files are long and uploading keeps the chat tidy.

One page per chat. If you are changing the library and the sessions page, do them in two separate chats. Mixing them is how Claude gets confused about which file it is meant to be returning.

Step 2 ◆ Tell it what you want

  1. Paste your Standing Instructions from Section 2.
  2. Underneath WHAT I WANT CHANGED, describe the change the way you would explain it to a person.
  3. Send it.

Vague gets vague. Compare these:

Not enoughMuch better
Fix the library pageAdd a new printable called the Christmas Fund Planner. It is 2 pages, it belongs in the budgeting filter and the sinking funds system, the file is christmas-fund-planner.pdf, and it should have the New badge.
Change the wordingOn the sessions page, change the line about cameras being optional so it also says people can join by phone if their internet is slow.
Make it betterThe paragraph under Do This First is too long. Cut it to about two sentences, keep the point about using last year’s numbers.

Step 3 ◆ Get the finished file back

  • Claude gives you the whole page and a list of what it changed. Read that list. It is your first check.
  • Copy the file using the copy button at the top of the code block.
  • Paste it into your text editor, save with the .html ending.
  • Double click the file to open it in your browser and look at it before it goes anywhere near Showit.

If the answer stops halfway. Very long files occasionally get cut off. Just reply: that got cut off, please continue from where you stopped. Or ask for it in two halves. Do not paste a half finished file into Showit.

Step 4 ◆ Paste it into Showit

  1. Select the whole file in your text editor with Command A or Control A, then copy.
  2. In Showit, click the page itself in the left menu. Not a text box, the page.
  3. Open Advanced Settings, then Custom Head HTML.
  4. Delete everything already in that box, then paste. Never paste underneath what is there.
  5. Publish.
  6. Open the live page in an incognito or private window and check it.

Member pages must be blank Showit pages. No text boxes, no images on the canvas. The pasted file is the whole page. Anything you drag on in Showit sits on top and looks broken.

Section five

Checking Claude’s work

Two minutes, every time, before it goes into Showit. This is the habit that keeps you safe.

  1. Read the change list. Claude tells you what it did. Does that match what you asked for? If it mentions changing something you did not ask about, ask why before you use it.
  2. Check the top and bottom. The file must start with <!DOCTYPE html> and end with </html>. If not, you have a fragment.
  3. Search for a long dash. In your text editor press Command F or Control F and search for a long dash character. There should be none. If there are, ask Claude to replace them with the diamond.
  4. Open it in your browser. Double click the saved file. Does the menu look right? Is the text you changed correct? Click two or three links.
  5. Look for the colour fix. Search the file for SHOWIT OVERRIDE ARMOUR. If it is gone, ask Claude to put it back.
  6. Then publish, and check the live page in incognito.

Shortcut. Paste the Ask Claude To Check A Page request from Section 4 into the same chat after it gives you the file. It will check its own work against that list, which catches most things in about ten seconds.

Section six

Jobs that skip Claude

Some things are faster done directly. No files, no chat.

The settings block, for the date and the price

The session date, the price shown on the sales page, the Facebook group link, and the checkout link all live in one block in Showit, not in the pages. Change it there and every page follows.

  1. Showit, Settings, then Advanced, then Head HTML. The site wide one.
  2. Find the block below, change the values, publish.
<script>
window.PP = {
  session: {
    start:     '2026-08-11T20:00:00-04:00',
    end:       '2026-08-11T20:45:00-04:00',
    timeLabel: '8:00 pm eastern',
    joinUrl:   'https://zoom.us/j/YOUR-ROOM-NUMBER',
    recurText: 'It runs on the second Tuesday of every month.'
  },
  communityUrl: 'https://www.facebook.com/groups/YOUR-GROUP',
  checkoutUrl:  'https://YOUR-CHECKOUT-LINK',
  pricing: {
    monthly: { amount: '$19',  per: 'per month, cancel anytime',
               second: 'Or $190 for the year and two months are free' },
    yearly:  { amount: '$190', per: 'per year, cancel anytime',
               second: 'That works out to $15.83 a month' }
  },
  supportEmail: 'hello@purposefulpennies.com'
};
</script>

Keep the quote marks and the commas. If a page shows the old date after you edit this, you have almost certainly lost one. Paste a fresh copy and change one line at a time.

The -04:00 matters. Use -04:00 from mid March to early November and -05:00 the rest of the year, or members in other states see the wrong time.

Section ten

Never do these five things

  1. Never publish without checking. Two minutes with Section 5. Claude is good and it is not infallible, and the live site is where your paying members are.
  2. Never edit or save these files in Word or Google Docs. They silently change quote marks and break the page. Plain text editors only.
  3. Never skip the backup copy. There is no undo once it is published.
  4. Never name a member page anything that does not start members-. It becomes public instantly and nothing warns you.
  5. Never change the price on the plan your existing members are on. Make a new plan for new joiners. Their founding rate was promised in writing.

When to send it to Genasys instead. Anything to do with the design or layout, a whole new kind of page, changing how the vault or library work, or anything you have asked Claude twice and it still is not right. Send us the file and say what you wanted. Quick for us, and it saves you an evening.
