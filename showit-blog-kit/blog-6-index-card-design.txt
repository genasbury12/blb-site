/* ============================================================
   PART 6 - THE BLOG INDEX: POST CARD DESIGN + SUPPORT CSS

   In Showit's blog INDEX template you design ONE post card
   and it repeats for every post. This file gives you:

   A) the exact recipe to build that card in Showit
   B) extra CSS to ADD to the bottom of your Custom CSS box
      (below what you already pasted) that helps style the
      repeating list + the category pills

   ============================================================
   A) BUILD THE POST CARD IN SHOWIT (exact values)
   ============================================================

   THE CARD CANVAS (the repeating item):
   - Background: #FFFFFF
   - Corner radius: 20
   - Border/stroke: 1px, color #2E1F27 at 16% opacity
   - Shadow: color #2E1F27, opacity ~38%, X 0, Y 26, blur 50
   - Inner padding: 0 top (image is flush), 26px sides/bottom
   - Gap between cards: 24px, 3 columns desktop, 1 column mobile

   INSIDE THE CARD, top to bottom:
   1. FEATURED IMAGE placeholder
      - flush to the top of the card, full card width
      - aspect ratio about 5:3 (e.g. 380 x 228)
      - corner radius 20 on TOP corners only, 0 on bottom
      - assign CSS class: blb-cardimg
   2. CATEGORY text placeholder (optional, sits on the image)
      - pill: background #FBF6EE, radius 60, padding 7x14
      - Karla Bold 10px, ALL CAPS, letter spacing 14%, #2E1F27
      - position: 14px from image top-left
   3. POST TITLE placeholder
      - Fraunces Medium (500), 20px, line height 1.25, #2E1F27
      - margin: 24px top (from image), 10px bottom
      - assign CSS class: blb-cardtitle
   4. EXCERPT placeholder
      - Karla Regular 15px, line height 1.65, color #6E5C63
      - 2-3 lines max
      - assign CSS class: blb-excerpt
   5. DATE text placeholder
      - Karla Regular 12px, letter spacing 4%, color #6E5C63
   6. "READ MORE" text/link
      - Karla Bold 12px, ALL CAPS, letter spacing 18%, #A93F63
      - assign CSS class: blb-readmore

   FEATURED (NEWEST) POST at the top, if your Showit list
   supports a featured layout: same recipe but one wide card,
   image LEFT half, text RIGHT half, title at 28-34px, with a
   gold script line above the title (Ephesis 24px, #BC8A47)
   that says: newest on the blog

   ============================================================
   B) ADD THIS CSS to the bottom of your Custom CSS box
   ============================================================ */
