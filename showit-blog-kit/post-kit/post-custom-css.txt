   ONLY. It replaces everything currently in that box. Your blog
   INDEX template keeps the index kit CSS you already have.

   CLASSES TO ASSIGN in Showit (Advanced -> CSS Classes, no dot):
     post title text        -> blb-title
     date / author line     -> blb-meta
     category text          -> blb-cats
     featured image         -> blb-featured
     the blog content area  -> blb-post

   (select the block -> Advanced -> Additional CSS class):
     blb-lead     on your opening paragraph  = bigger intro text
     blb-dropcap  on your opening paragraph  = big fancy first letter
     blb-btn      on any link or button      = pink pill button
     blb-note     on a paragraph             = blush callout card

   Styling shows on the PUBLISHED site, never in the editor.
   ============================================================= */
